# Visualization outputs

- `suicide_by_age_gender_country.png`: descriptive views of available country and sex rate rows.
- `correlation_heatmap.png`: unadjusted association between both-sex crude suicide rates and joined GDP/population fields where available.
- `trend_plot.png`: in-sample linear trend over observed years, not a forecast.

See the root `README.md` for units, source limitations, and nonclinical scope. The earlier `forecast_plot.png` was removed because it did not evaluate an out-of-sample forecast.
